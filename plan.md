# vindR plan

Native macOS browser. SwiftUI shell + WKWebView. No Chromium. No third-party packages.

1. Browser shell: compact/hideable toolbar, URL/search, navigation, keyboard shortcuts.
2. Privacy: WKContentRuleList blocker, persistent/private session switch, JavaScript setting.
3. Tabs: tab strip, 5-minute background freeze, WebContent recovery.
4. Reading: dark CSS injection, clean reader mode.
5. Tools: opt-in JavaScript console, network/application inspectors, app terminal,
   and process list. Explicit permissions and warnings.
6. Notes: local sketchpad and text notes stored on-device.
7. Settings: blocker, JavaScript, dark mode, search engine, freeze timer, data clearing.

Useful later: find-in-page, zoom, mute tab, HTTPS indicator,
permission controls, session restore, bookmarks, history off switch.

Constraints: macOS 13+, native frameworks only, minimal background work, no telemetry.
