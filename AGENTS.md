# vindR agent rules

- Read `plan.md` and `tasks.md` before coding.
- Work only the first unchecked task unless asked otherwise.
- Keep architecture native, small, and dependency-free. Prefer SwiftUI, AppKit, and WebKit.
- Apply KISS/YAGNI. Avoid abstractions until a second use exists.
- Update `tasks.md` after every meaningful change and before stopping.
- Update `features.md` whenever a user-visible feature is added, changed, or removed.
- Update `user-manual.md` whenever installation, user-facing behavior, safety guidance, or shortcuts change.
- Run `swift build` after source changes. Record blockers honestly.
- Preserve privacy defaults. Never add telemetry.
